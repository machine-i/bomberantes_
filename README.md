# BomberAntes - Bomberman de cadeirAntes

This is a game inspired by the classic Bomberman, developed using only JavaScript, HTML and basic CSS, without the use of external frameworks. Includes multiplayer mode for up to 4 players!

## How to Play

- **Access**: https://bomberantes.onrender.com/

### Solo Mode
1. Choose "Modo Solo" from the main menu.
2. Use the arrow keys (or WASD) to move the player around the map.
3. Press the SPACE key to place bombs.
4. The bombs explode after 2 seconds, in a cross shape.
5. Destroy the breakable walls with the bombs.
6. Be careful not to get hit by the bomb explosion!

### Multiplayer Mode
1. Choose "Criar Sala" to start a new game or "Entrar em Sala" to join an existing game.
2. Share the room ID with your friends (up to 4 players).
3. The room creator can start the game when everyone is ready.
4. Play with the same controls as solo mode, but now with your friends!

## Controls

- **Movement**: Directional arrows (↑, ↓, ←, →) ou WASD
- **Place bomb**: Spacebar

## Game Features

- 2D grid map with fixed (indestructible) and breakable walls.
- Controllable player with movement in four directions.
- Bomb system with cross explosion.
- Collision with walls prevents player movement.
- Explosions can destroy breakable walls.
- The player loses a life if hit by an explosion.
- **New!** Online multiplayer for up to 4 players.
- **New!** Room system to play with friends.
